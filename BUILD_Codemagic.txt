PROFITRIDE 3.0 - BUILD

1. Creează sau golește un repository GitHub.
2. Încarcă TOT conținutul acestui folder în rădăcina repository-ului.
3. Verifică să existe:
   app/
   build.gradle
   settings.gradle
   gradle.properties
   codemagic.yaml
4. În Codemagic conectează repository-ul.
5. Check for configuration files.
6. Start new build.
7. Descarcă ProfitRide.apk din Artifacts.
